# Kişisel Portföy — Başlangıç

## Dosyalar
- `index.html`: Sayfa içeriği
- `style.css`: Tasarım ve mobil uyum
- `script.js`: Türkçe/İngilizce dil değiştirme

## Bilgisayarında açma
1. ZIP dosyasını bir klasöre çıkar.
2. Klasörü Visual Studio Code ile aç.
3. `index.html` dosyasını tarayıcıda aç. İstersen VS Code içinden Live Server eklentisini kullanabilirsin; eklenti zorunlu değildir.

## Yayınlamadan önce
- `EMAIL_ADRESIN_BURAYA` kısmını kendi e-posta adresinle değiştir.
- LinkedIn ve GitHub bağlantılarını kendi profillerinle güncelle.
- Proje kartlarını gerçek projelerinle değiştir; olmayan deneyim veya projeleri varmış gibi yayımlama.
- İşverenine ait gizli verileri, kodları veya şirket bilgilerini yayımlama.

## Ücretsiz yayın
Bu statik site GitHub Pages veya Cloudflare Pages üzerinde yayımlanabilir. İlk sürüm için Node.js sunucusu veya veritabanı gerekmiyor.
